# ADR-0013: Golden Business Outcome Harness and golden-answer governance

- **Status**: Accepted (locked V1.1)
- **Date**: 2026-08-15

## Decision

Implement a **Golden Business Outcome Harness** as a required release-control component:

- Version-controlled scenario registry (`tests/golden/`)
- Production-path driver (same application/domain services as production)
- **Independent expected oracle** — expected values are never regenerated by code under test
- Trace comparator, evidence reporter and release gate

First locked pack: **2026 Marketplace MAGI** (G-MAGI-01 through G-MAGI-10). Decision states: SAFE, WATCH, LIKELY OVER, OVER, INDETERMINATE.

## Consequences

- AC-ARCH-13 through AC-ARCH-17; Milestone 5 exit gate.
- Golden mismatches block release; no tool or AI may auto-approve expected results.
