# Independent expected oracle

This directory holds **manually reviewed** expected inclusions, exclusions, subtotals, ranges and final status for golden scenarios (V1.1 §11.2, ADR-0013).

Rules:

- Expected values are never regenerated by the code under test or by an AI process.
- A failing test is investigated before any expected value is changed.
- Owner acceptance is required for the initial expected results and for any material business-meaning change.

Current files are **approved** (`status: approved`, `approved_at: "2026-08-18"`). Do not regenerate numbers. Nested G-MAGI-10 timing adjustment `G10-ADJ-1` is owner-approved; posted MAGI matches adjusted forms.
