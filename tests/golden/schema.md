# Golden scenario schema

Required fields from V1.1 §11.2. Files under `tests/golden/scenarios/` are the registry.
Expected numeric values live in `tests/golden/oracle/` after owner approval — never regenerated by code under test (ADR-0013).

| Field | Purpose |
|-------|---------|
| `scenario_id` / `scenario_version` | Stable identity and controlled evolution |
| `business_question` / `requirement_ids` | Owner outcome and governing requirements |
| `as_of_date` / `coverage_year` | Prevents present-day rules from contaminating the case |
| `input_facts` / `provenance` | Synthetic or approved snapshot facts and completeness |
| `rule_set_id` / `calculation_version` | Effective-dated policy and executable logic |
| `expected_included` / `expected_excluded` | Classification decisions |
| `expected_subtotals` / `expected_range` | Calculation path and uncertainty |
| `expected_status` / `expected_warnings` | Decision-support behavior |
| `tolerance` / `precision_policy` | Exact fixed-scale unless a documented tolerance applies |
| `approval` / `rationale` / `approved_at` | Why the expectation is authoritative |

Milestone 0 stubs set `approval.status: pending-owner` and leave expected numerics empty.

Proposed G-MAGI-01–10 facts and oracles live in `scenarios/` and `oracle/`. They are owner-approved as of 2026-08-18. Rule inputs: `tests/golden/rules/marketplace-magi-2026.yaml`.
