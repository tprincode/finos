# Golden Business Outcome Harness (ADR-0013)

Version-controlled scenario files with stable IDs, independent expected oracle,
and production-path driver. First locked pack: 2026 Marketplace MAGI (G-MAGI-01 through G-MAGI-10).

See `docs/architecture/` and ADR-0013.

## Harness crate

`crates/golden-harness` loads scenarios, writes evidence reports, enforces crate-graph/UI-SQL invariants, loads the M2 seed through production-path commands, runs the M3 dividend slice, runs the M4 lots/ROI slice, compares MAGI projections to owner-approved oracles, and runs the Calculator Plan / burndown slice.

- **Milestone 5 exit gate:** the locked Marketplace MAGI pack must **pass** through production application/domain services (`cargo test -p golden-harness --features magi-gate`).

## Test levels (V1.1 §11.3)

| Level | Coverage |
|-------|----------|
| L0 — Invariants | Rules that must always hold |
| L1 — Golden calculations | Deterministic business calculations independent of UI |
| L2 — Component workflows | Commands and events across bounded components |
| L3 — Owner journeys | End-to-end questions in business language |
| L4 — Recovery and portability | Backup/restore, handoff, SQLite/PostgreSQL |

## Layout

- `schema.md` — required scenario fields
- `scenarios/` — registry (G-MAGI-01–10 stubs)
- `oracle/` — owner-approved expected MAGI results (never regenerated by code under test)
- `rules/` — 2026 Marketplace MAGI rule inputs (threshold derivation + safety reserve)
- `fixtures/` — Fidelity/Schwab dividend CSVs and MAGI tax-form stubs
- `fixtures/` — Fidelity- and Schwab-shaped dividend CSVs for the M3 L2 slice
